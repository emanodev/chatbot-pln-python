# Chatbot PLN com Voz e Análise de Sentimento

Chatbot desenvolvido em Python utilizando técnicas de Processamento de Linguagem Natural (PLN).

## Funcionalidades

- Chatbot baseado em NLTK
- Interface gráfica com Tkinter
- Reconhecimento de voz
- Síntese de voz
- Análise de sentimento com TextBlob
- Histórico de conversa salvo automaticamente

## Tecnologias

- Python
- NLTK
- TextBlob
- Tkinter
- SpeechRecognition
- pyttsx3

## Executar

1. Instalar dependências

pip install -r requirements.txt

2. Executar

python chatbot_pln.py
